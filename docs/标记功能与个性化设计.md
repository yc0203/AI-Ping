# 标记功能与个性化设计

本文件记录实施前讨论的改装方向。当前已实现的功能与限制请查看 README；本文件中的预设、主题等条目不代表均已完成。

## 核心交互

直接给现有标记绑定功能，不要求用户记住第二套功能图标。先打开轮盘、选择标记，再执行对应动作。原信号仍可作为“仅标记”动作使用。

每个标记分别配置：图标、功能名称、动作、音效、主题色、动画预设。修改图标或音效不改变动作；更换动作不强迫更换图标。

建议初始映射（可更改）：

| 外观 | 功能名称 | 选中后的下一步 |
| --- | --- | --- |
| 问号 | 解释这里 | 框选不懂的按钮、面板或报错，再发送给 AI |
| 集合／协助 | 给操作方案 | 框选相关界面，补充想完成的目标 |
| 视野 | 截图翻译 | 框选文字区域，再进行识别和翻译 |
| 前进 | 划词翻译 | 回到原软件拖动选择文字，再读取选区并翻译 |
| 普通信号 | 仅截图 | 框选后复制或保存 |
| 其他标记 | 仅标记 | 保留原来落点动画，无后续动作 |

这些只是默认映射，不把标记的游戏语义硬编码成固定功能。

## 文字提示

1. 轮盘打开：每个图标旁显示简短功能名称；使用原来的暗色、金色线条和青色文字体系，避免像网页按钮一样覆盖图标。
2. 鼠标指向扇区：保留扇区高亮和图标放大；中心显示所选功能名称，下面显示下一步，如“松开后框选区域”。
3. 松开选择：收起轮盘，播放该标记原风格的短暂落点动画和配置音效，再显示模式提示。
4. 动作就绪：提示“截图翻译 · 请框选区域 · Esc 取消”。划词模式提示“划词翻译 · 请在原软件中选择文字 · Esc 取消”。框选期间不持续重复播放音效。
5. AI 处理中：显示“正在翻译／分析”，可以取消。答案显示后允许追问，不重复触发新截图。
6. 一次操作完成或取消后退出模式，恢复普通输入；不能仅因标记动画淡出就让用户不知道当前模式仍在等待动作。

划词模式放行原软件的鼠标选区；截图模式由框选窗口接管输入。如果原软件不能提供选中文字，应提示“无法获取所选文字”，允许切换截图翻译，不默默发送旧剪贴板。

## 保持原有显示风格

现有标记的动感主要由透明图标配合 CSS 动画组成：弹出、轻微浮动、落地辉光、扩散光圈和淡出，并非每个标记都只是播放 GIF。因此自定义静态图标也能套用相同动画，保持节奏和视觉一致。

优先保留：原轮盘结构、边框材质、扇区高亮、选中放大、标记色彩、光圈和短时淡出。

新增文字：暗色半透明底、细金边、功能色小标题，跟随标记短暂出现；文字清楚但不遮挡图标。屏幕边缘自动避让，长标题设置长度限制并在设置页解释。等待操作的模式提示独立显示，保持可读。

自定义图标默认推荐透明 PNG/WebP，统一尺寸和可视边距，并套用原有动画。可选支持 GIF／动画 WebP；内部动图与外部光圈叠加容易杂乱，因此预览中允许选择“原版弹出”“轻柔浮动”“仅淡入淡出”，而不是不加限制地叠加全部效果。

AI 答案面板可以沿用暗色和细金边，但正文保持清晰静止；不让大段文字跟着标记上下浮动。

## 个性化设置

在现有设置中为每个标记增加编辑项：

- 功能：仅标记、划词翻译、截图翻译、解释这里、给操作方案、仅截图。
- 显示名称：可编辑短标题；动作说明由功能生成，避免更名后误导用户。
- 图标：选择本地图片，预览裁切和透明边距；恢复原图。
- 音效：选择本地音频、试听、调节音量、静音、恢复原音效。对格式、时长、大小设限，并验证可解码。
- 视觉：主题色、大小、持续时间、动画预设。默认继承原效果。
- 预览：同一编辑页直接试听并演示轮盘选中、标记落点、文字提示。
- 重置：单个标记恢复默认；导入素材复制到应用数据目录，避免源文件移动后失效。

自定义表情导入是原项目已有能力；自定义信号图标、逐标记音效、功能绑定及文字提示需要新增，不能误认为现有设置已包含。

## 实现与验证

WheelItem 增加标签与动作提示，Wheel 更新中心文案；spawnPing 增加可选功能文案。功能映射进入独立 ActionBinding 设置，不让房间成员的远程标记触发本机 AI、截图或文本读取。

自定义资源由主进程导入、校验并通过受控协议读取；渲染层只获得已登记资源的地址。动作分发由主进程验证本机来源，处理准备、选择、预览、发送、处理中、完成、取消各状态。

先实现标记绑定、文字提示和预览，再接入截图／划词状态机和模型服务。当前轮盘和落点动画可复用，截图与答案窗口另建，以解决原悬浮层默认鼠标穿透且不获取焦点的问题。

重点验证：图标和文字不重叠；屏幕边缘可读；更换素材后动画协调；静音有效；AI 等待可取消；划词不阻断原软件选择；框选取消后输入恢复；自定义素材丢失有回退；远程标记和设置预览不执行 AI 动作。
