# lolPing 体验与 AI 改装评估

> 实施前的历史评估。当前功能与安装方式以仓库 README 和 INSTALL 文档为准。

## 当前安装

- 官方仓库：https://github.com/darrenprx/lolPing
- 安装版本：v0.5.1；安装目录：<工作目录>\app
- 安装包：downloads\lolPing-Setup-0.5.1.exe
- SHA256：42b88183e07999e305ab9d2e7ce150797d2b94cfe6f60a0d237fba469523ad4a（与 GitHub 发布记录一致）
- 对应源码：source；提交 b1181e9ea53972992a503d078fdb06792ffa087e
- 双击“启动lolPing.cmd”启动；Alt + 左键拖动呼出信号轮盘；Ctrl + 左键拖动呼出表情轮盘；Ctrl + Alt + P 暂停/恢复。
- 设置窗口关闭后仍在托盘运行；右键托盘图标退出。设置默认保存在 %APPDATA%\lolPing\settings.json，程序安装在当前文件夹不代表配置也在这里。

## 判断

可以在此基础上实现“标记区域翻译、截图解释软件界面、根据截图提供操作方案”。当前版本只有信号和表情，没有这些 AI 功能；下面是源码评估后的建议，尚未实施。

代码为 MIT 许可证，允许修改、分发和商业使用，保留原版权和许可证说明。游戏图标、音效不在 MIT 授权范围内；如果改成自己的产品，建议使用自己的图标和声音。

## 推荐的第一版

保留原有信号体验，增加独立的 AI 轮盘或模式，先提供三个动作：

| 动作 | 交互 | 输出 |
| --- | --- | --- |
| 翻译 | 选择动作，框选文字区域 | 原文、中文译文、复制按钮 |
| 解释这里 | 选择动作，框选按钮、面板或报错 | 解释含义、用途、下一步，并可追问 |
| 给操作方案 | 选择动作，框选相关界面，输入想完成的目标 | 根据可见界面提供步骤，说明缺少的上下文 |

单点标记可默认取周围一块截图，但必须允许调整区域；过小的截图往往看不到按钮标签、窗口名称或报错上下文。先做“框选后解答”，之后再加智能识别窗口或控件。

流程：轮盘选择动作 → 收起标记和轮盘 → 框选区域 → 预览截图，可补充问题 → 用户发送 → AI 流式回答 → 保留截图上下文继续追问。

解释界面和提供建议能实现；直接点击、输入和操控其他软件需要另做自动化模块，不能把“看懂截图”当作“已经执行”。第一版先完成解答和步骤建议。

## 可复用的源码与新增模块

- source/src/main/inputBridge.ts、source/native/hook-helper：复用全局输入与手势；框选期间暂停原手势，结束或取消时恢复，避免吞掉鼠标输入。
- source/src/renderer/overlay/main.ts、wheel.ts：复用轮盘选择逻辑。目前选择后调用 reportPing，可扩展为独立 action 事件，不要把 AI 动作塞进房间信号协议。
- source/src/main/overlayManager.ts：已有显示器 ID 和落点坐标，悬浮层默认鼠标穿透且不获取焦点。截图框选和可交互答案应使用独立窗口，不能直接沿用当前窗口属性。
- source/src/main/coords.ts：复用物理像素与 DIP 转换，新增截图裁剪时核对截图实际尺寸，处理不同缩放、多显示器和负坐标。
- 新增 captureService：通过 Electron desktopCapturer 获取屏幕图像、按实际图像尺寸裁剪；先隐藏自身悬浮层，防止把轮盘和标记截进去。失败或受保护画面要给出明确提示。
- 新增 aiService：在主进程统一调用支持图片输入的模型，支持用户配置服务地址、模型和凭证，处理超时、取消、流式回答和错误；密钥不暴露给渲染页面。
- 新增 selectionWindow 与 answerWindow：框选、截图预览、补充问题、复制答案、追问；答案窗口按屏幕边缘避让。
- 新增设置：AI 服务配置、目标语言、动作快捷键。普通信号保持原样，AI 截图不经现有房间网络发送。

翻译可以先直接用视觉模型完成，OCR 不是第一版的必需项；要做原位置覆盖译文和精确文字框，再增加 OCR 布局识别。

## 验收重点

1. 100%/125%/150% 缩放和副屏裁剪位置准确，截图不包含自身轮盘。
2. Esc、右键、关闭窗口、AI 超时都能退出当前操作，输入正常恢复。
3. 无凭证、断网、模型不支持图片时有清楚提示；不会把其他屏幕或多余区域发送给模型。
4. 软件说明根据截图作答；看不到的步骤要求补充上下文，不假装了解全部界面。
5. 原有标记、表情和暂停快捷键仍正常；AI 动作与远程房间事件分开。
