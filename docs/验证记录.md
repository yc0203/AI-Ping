## 2026-10-16 黑块与闪烁兼容修复

用户报告打开面板有黑块和闪烁。检查时原版 AI 面板能正常显示，未稳定复现原故障，因此尚不能确认唯一触发原因。

- Windows 默认关闭硬件加速，运行时确认 `gpu_compositing` 为 `disabled_software`。仅显式传入 `--enable-gpu` 时恢复硬件路径，便于后续比较。
- Windows 原版设置面板移除透明 Mica 背景，原生窗口与网页均提供不透明背景；面板停止后台降频，避免被全屏透明标记层遮盖时停止绘制。
- 覆盖层只在实际可见状态变化时执行显示／隐藏，首次绘制完成前不显示，也不在截图期间提前显示。
- 726 项自动测试、TypeScript 检查与生产构建通过。
- 当前 NVIDIA RTX 3050 Laptop 环境中检查了连续桌面画面、透明问号动画与设置页面，未见黑色全屏覆盖；三次框选截图返回流程通过。

本次连续桌面画面保存在忽略的 `.local/render-check` 中。短时验证不代表所有显卡状态下都已完全消除闪烁，需要结合用户后续体验确认。

## 2026-10-16 框选与就地回答

- 截图背景禁用原生图片拖动；按住左键拖动、松开确认，实时显示选区宽高。点击而未拖出矩形时不提交，也不再报“面积太小”。
- 处理 pointercancel、鼠标捕获丢失，以及前一次点击的释放事件晚于新拖动到达的情况，避免新选区被清空。
- 截图或划词后在选区／鼠标附近显示独立结果浮窗，预览后显式发送；流式回答、复制、追问、停止、重选、展开完整面板均可直接操作。浮窗不会获得配置密钥、导入素材等面板专属操作的权限。
- 731 项单元测试通过，包含多显示器坐标、屏幕边缘和小屏幕的浮窗定位检查；TypeScript 与生产构建通过。
- `tools/capture-result-smoke.mjs` 在实际 Electron 中发送鼠标按下／移动／松开事件，覆盖普通点击、反方向框选、浮窗预览、配置权限、流式显示、连续追问与展开后保留对话。本机 mock 服务只监听 loopback，没有使用真实 API 服务发送这些测试截图。

交互自动化占用框选窗口时，真实鼠标或 Esc 输入会中断测试。脚本结束会取消残留框选并恢复原 AI 设置。
